# tokaAnchor

Nukkit-MOT 伺服器維運外掛：封禁與關聯帳號、排程重啟、清理、維護模式、登入限制。指令說明用 `/anchor help [頁]`。

## 離線玩家的排隊指令

`/c <玩家> <指令>`（或 `/anchor run ...`）找不到線上的玩家時，如果 tokaProfiles 認得這個名稱，指令會先排隊，等那位玩家下次登入時以他的身分執行；不認得就維持「目標玩家不在線上」。tokaProfiles 不存在時不會排隊。

- 排隊的指令存在外掛的資料庫（tokaStorage），重啟後還在。
- 玩家登入後等幾個 tick 再依排入的順序執行，每個指令一行記在後台；排入的管理員在線上時會收到通知。指令先從佇列移除再執行，所以當機也不會執行兩次；執行前玩家就離開的，沒執行的放回佇列最前面。
- `/anchor run list [玩家]`：列出有等待指令的玩家，或某位玩家的指令與排了多久。
- `/anchor run cancel <玩家>`：取消那位玩家等待中的所有指令。
- 以上都需要 `tokaanchor.admin`。離線玩家的名稱要自己打，指令補全只列出線上的玩家。

`config.yml` 的 `run.queue`：

| 設定 | 預設 | 說明 |
| --- | --- | --- |
| `max-per-player` | 10 | 每位玩家同時最多排幾個，滿了拒絕 |
| `max-length` | 256 | 單一指令最大字元數，更長的拒絕 |
| `max-age-days` | 30 | 排隊超過幾天就丟掉（載入資料與玩家登入時檢查） |
| `join-delay-ticks` | 10 | 玩家登入後等幾個 tick 再執行 |
